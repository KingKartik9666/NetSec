# NetSec for Windows

Download the Windows app from the [NetSec v0.3.0 release](https://github.com/KingKartik9666/NetSec/releases/tag/v0.3.0-windows):

- **Installer:** [NetSec-Setup-0.3.0-x64.exe](https://github.com/KingKartik9666/NetSec/releases/download/v0.3.0-windows/NetSec-Setup-0.3.0-x64.exe)
- **Portable installed app:** [NetSec-Windows-Installed-v0.3.0.zip](https://github.com/KingKartik9666/NetSec/releases/download/v0.3.0-windows/NetSec-Windows-Installed-v0.3.0.zip)

The portable archive contains the installed application folder. Extract the complete folder and run `NetSec.exe`. The installer provides the normal Windows installation experience.

The release also includes SHA-256 checksums for both downloads. The app is built for 64-bit Windows.
