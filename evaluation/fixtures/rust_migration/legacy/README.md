SHA256 and original location are recorded in `provenance.json`. It contains a
saved DataSense validation-observation analysis with 170 SHAP feature entries,
template reasoning and selected evidence explanations.

This export predates the current `features`, `feature_coverage` and adapter
`capability_errors` fields. It is a historical response example, not the current
complete API schema, a newly executed prediction, or an independent benchmark.
